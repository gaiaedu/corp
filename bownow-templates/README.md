# BowNow フォーム設定・自動返信＆管理者通知メール 完全再現テンプレート集

> **BowNowのフォームインポート機能の有無について**
> BowNowには、microCMSのように「JSONファイル等で外部からフォーム定義そのものをインポートする機能」は用意されていません（リードのCSVインポート機能のみです）。
> ただし、既に同じBowNowアカウント内に別サイト（本社サイト `www.gaia-edu.co.jp` 等）のフォームがある場合は、**「フォーム・ファイル ＞ フォームを管理する」一覧の「フォームの複製」アイコン**から既存フォームをコピーして差分項目だけを追加すると最短で作成できます。

## 2. 完了画面（サンクスページ）設定（旧サイト完全同一）

BowNowの「完了画面設定」では、以下の2通りのどちらも旧サイトと同一になります。

### パターンA：BowNowの完了画面メッセージに表示する場合（コピペ用）
```text
この度はお問い合わせ頂きましてありがとうございます。

ご連絡は受付順に正確かつ迅速に対応させていただいておりますが、場合によってはお時間をいただく場合がございます。
ご迷惑をおかけいたしますが、よろしくご理解くださいますようお願い申し上げます。
```

### パターンB：サイト内の完了ページURLへリダイレクトさせる場合
サイト側に旧サイトと100%同一の完了ページを用意済みです。
* 検証環境リダイレクト先：`https://gaiaedu.github.io/corp/inquiry/thanks/`
* 本番環境リダイレクト先：`https://corp.gaia-edu.co.jp/inquiry/thanks/`
